## 🐛 Known Issues

### Current (v1.0.0)

None known at this time.

### Performance Notes

- Very large files (>100MB) may timeout
- Complex PDFs may take time to process
- Some SVG features may not convert perfectly
- Recommended: Use latest browsers

### Browser Compatibility

- IE 11: Not supported (use Chrome)
- Very old browsers: Limited support
- Mobile Safari: Fully supported
- Android Chrome: Fully supported
