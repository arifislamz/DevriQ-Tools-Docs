## ❓ Frequently Asked Questions (FAQ)

**Q: What is Natural Sort?**

A: Natural sort orders strings containing numbers logically (1, 2, 10) instead of pure ASCII alphabetical order (1, 10, 2).

**Q: Can it sort numerically by first number on each line?**

A: Yes, select 'Numerical Sort' to order lines by their leading or embedded numbers.

**Q: Is my list uploaded to a server?**

A: No, all sorting executes in local browser JavaScript.
