## ❓ Frequently Asked Questions (FAQ)

**Q: Is it safe to paste live authentication tokens here?**

A: Yes, absolutely. Unlike many online decoders, DevriQ processes JWTs entirely in your local browser with zero server transmission.

**Q: Can I edit payload claims?**

A: The tool is designed for rapid inspection and debugging; edited payloads invalidate existing signatures unless re-signed.

**Q: What algorithms are recognized?**

A: Recognizes all standard algorithms including HS256, HS384, HS512, RS256, RS512, and ES256.
