## ❓ Frequently Asked Questions (FAQ)

**Q: What does the 8-digit HEX code mean?**

A: The last two digits in an 8-character HEX (e.g., #3B82F680) represent the alpha (opacity) channel.

**Q: Why do CMYK colors look slightly different than RGB?**

A: RGB uses an additive light spectrum (screens), while CMYK uses a subtractive ink spectrum (print), which has a narrower color gamut.

**Q: Is there a color picker tool included?**

A: Yes, an integrated eyedropper and visual picker allow picking any color on your screen.
