## ❓ Frequently Asked Questions (FAQ)

**Q: What is the difference between 502 and 504?**

A: 502 Bad Gateway means the upstream server returned an invalid response; 504 Gateway Timeout means the upstream server did not respond in time.

**Q: Why is 418 I'm a teapot in the list?**

A: It was introduced in RFC 2324 as an April Fools' joke but remains officially reserved in IANA standards.

**Q: Can I access this reference offline?**
