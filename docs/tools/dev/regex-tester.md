## 💡 Best Practices & Pro Tips

- ✅ **Pro Tip:** Always escape special characters like dots (`\.`) when matching literal file extensions or domains.
- ✅ **Pro Tip:** Use non-capturing groups `(?:...)` when grouping expressions without needing separate captured tokens.
- ✅ **Pro Tip:** Test against edge cases and negative examples to prevent catastrophic backtracking.
