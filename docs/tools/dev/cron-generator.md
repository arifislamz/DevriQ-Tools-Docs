## ❓ Frequently Asked Questions (FAQ)

**Q: What does `* * * * *` mean?**

A: It runs once every minute of every hour, day, month, and week.

**Q: What is the difference between `?` and `*` in Quartz?**

A: `*` specifies all values, while `?` is used in Day-of-month or Day-of-week when no specific value is required.

**Q: Is this compatible with GitHub Actions?**

A: Yes, the standard 5-part POSIX cron syntax generated is fully compatible with GitHub Actions workflow triggers.
